# Nexus — AI Search Engine

Nexus is a learning-driven AI search engine that I’m building from scratch to understand how modern search and AI systems work.

The project will progressively evolve from traditional keyword search to semantic search, reranking, RAG, evaluation, and eventually production-ready AI engineering.

## Current Progress

### Stage 0 — Keyword Search

Currently implemented:

- Text tokenization and normalization
- Inverted index
- Keyword-based retrieval
- Basic relevance scoring
- Result ranking
- Handling empty and unknown queries
